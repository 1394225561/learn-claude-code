# 学习者背景画像

用户有 6 年前端开发经验，精通 JavaScript/TypeScript，熟悉前端常见模式（事件系统、组件架构、模块系统）。对 Python 只有阅读项目的经验，没有独立编写过。AI/LLM 应用开发完全零基础，未使用过任何 AI API。

这意味着：编程概念（循环、函数、数据结构、设计模式）不需要教。Python 特有语法（缩进、dataclass、类型提示、字典/列表推导式）在出现时需要重点标注。AI 概念（API 调用、tool use、prompt engineering、agent loop）需要从头教，但可以用前端熟悉的概念做类比（如：tool dispatch map ≈ 路由器，hook system ≈ 事件发射器，message bus ≈ 发布/订阅）。

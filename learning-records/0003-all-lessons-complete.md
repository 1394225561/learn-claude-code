# 全部 20 课 HTML 课程编写完成

20 课 HTML 教学文件已全部创建，覆盖 learn-claude-code 项目的全部核心机制。每课结构统一：问题描述 → 核心思路 → 代码解析 → 前端类比 → Python 语法速查 → 动手实验 → 测验 → 下一步。所有课程使用共享样式表和测验组件。

课程分为 6 个层次：
- 核心能力（s01-s04）：循环、工具、权限、Hook
- 复杂任务（s05-s08）：规划、子Agent、技能、压缩
- 记忆与恢复（s09-s11）：记忆、提示词、错误恢复
- 长期任务（s12-s14）：任务图、后台任务、定时
- 多Agent协调（s15-s18）：团队、协议、自治、工作树
- 扩展组装（s19-s20）：MCP、综合

**Why:** 课程是学习的主要载体，完成全部课程意味着学习路径已完整铺设。
**How to apply:** 学习者可以按顺序学习，也可以跳到感兴趣的章节。每课都有测验可以检验理解。

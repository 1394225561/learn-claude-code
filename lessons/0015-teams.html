MessageBus：文件邮箱

class MessageBus:
    def send(self, from_agent, to_agent, content, msg_type="message"):
        msg = {"from": from_agent, "to": to_agent,
               "type": msg_type, "content": content,
               "timestamp": time.time()}
        inbox = MAILBOX_DIR / f"{to_agent}.jsonl"
        with open(inbox, "a") as f:
            f.write(json.dumps(msg) + "\n")  # 追加写入

    def read_inbox(self, agent):
        inbox = MAILBOX_DIR / f"{agent}.jsonl"
        if not inbox.exists():
            return []
        msgs = [json.loads(line) for line in inbox.read_text().splitlines()]
        inbox.unlink()  # 破坏性读取：读完就删
        return msgs
破坏性读取：读完邮件后删除文件。这样每条消息只会被处理一次，就像从队列中消费消息。

前端类比

这就是 Web Workers 通过 postMessage 通信，或者微前端架构通过消息代理共享数据。破坏性读取像从 RabbitMQ/Kafka 消费消息。

第 7 课: Skill Loading — 技能加载

Agent 需要很多知识，但不是每次都用到全部。这一课实现按需加载，只在需要时才注入完整知识。

问题：知识太多，上下文装不下

如果把所有技能文档都塞进系统提示词，token 会被大量占用，留给真正对话的空间就少了。

两级注入

  启动时（轻量）
  ┌─────────────────────────────────┐
  │ 系统提示词 += 技能目录           │
  │ "code-review: 检查代码质量..."   │  ~100 tokens/技能
  │ "pdf: 生成 PDF 文档..."         │
  └─────────────────────────────────┘

  需要时（按需加载）
  ┌─────────────────────────────────┐
  │ 模型调用 load_skill("code-review")│
  │ → 返回完整 SKILL.md 内容         │  ~2000 tokens/技能
  └─────────────────────────────────┘

代码实现

from pathlib import Path
import yaml

SKILLS_DIR = Path("skills")
SKILL_REGISTRY: dict[str, dict] = {}

def _parse_frontmatter(text: str) -> tuple[dict, str]:
    """解析 YAML frontmatter（Markdown 文件顶部 --- 包裹的部分）"""
    if not text.startswith("---"):
        return {}, text
    parts = text.split("---", 2)
    frontmatter = yaml.safe_load(parts[1]) or {}
    body = parts[2].strip() if len(parts) > 2 else ""
    return frontmatter, body

def _scan_skills():
    """启动时扫描 skills/ 目录，只读名字和描述"""
    for skill_dir in sorted(SKILLS_DIR.iterdir()):
        skill_file = skill_dir / "SKILL.md"
        if not skill_file.exists():
            continue
        frontmatter, body = _parse_frontmatter(skill_file.read_text())
        SKILL_REGISTRY[skill_dir.name] = {
            "name": skill_dir.name,
            "description": frontmatter.get("description", ""),
            "path": str(skill_file),
        }

def load_skill(name: str) -> str:
    """模型调用时，返回完整内容"""
    skill = SKILL_REGISTRY.get(name)
    if not skill:
        return f"Unknown skill: {name}"
    return Path(skill["path"]).read_text()

# 系统提示词只注入目录
def build_system():
    catalog = "\n".join(
        f"- {s['name']}: {s['description']}"
        for s in SKILL_REGISTRY.values()
    )
    return f"Available skills:\n{catalog}\nUse load_skill(name) to load."

前端类比

这就是 React 路由懒加载：路由表（系统提示词）告诉 app 有哪些页面，但组件代码只在用户导航到该路由时才加载。

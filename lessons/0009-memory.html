第 9 课: Memory — 记忆系统

Agent 每次对话都从零开始。这一课让它跨会话记住用户偏好和项目事实。

三个子系统

  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
  │  Selection   │    │  Extraction │    │ Consolidation│
  │  选择相关记忆 │    │  提取新记忆  │    │  合并去重     │
  └──────┬──────┘    └──────┬──────┘    └──────┬──────┘
         │                  │                  │
    对话前注入          每轮结束后           文件数超阈值

存储格式

记忆存储为 .memory/ 目录下的 Markdown 文件，带 YAML frontmatter：

---
name: user-preferences
description: 用户喜欢简洁的代码风格
type: user
---

用户偏好：
- 代码风格：简洁，不要过度注释
- 语言：Python，不用 TypeScript
- 测试框架：pytest

Selection：对话前注入相关记忆

def select_relevant_memories(messages):
    """用 LLM 从记忆目录中挑选相关的"""
    catalog = "\n".join(f"- {m['name']}: {m['description']}" for m in all_memories)
    recent = messages[-4:]  # 最近 2 轮对话

    response = client.messages.create(
        model=SMALL_MODEL,
        messages=[{"role": "user", "content": f"对话:\n{recent}\n\n记忆目录:\n{catalog}\n\n选出相关的记忆文件名（JSON 数组）"}],
    )
    return parse_filenames(response)

Extraction：每轮结束后提取新记忆

def extract_memories(messages):
    """对话后，提取用户偏好和项目事实"""
    response = client.messages.create(
        model=SMALL_MODEL,
        messages=[{"role": "user", "content": f"从这段对话中提取用户偏好或项目事实:\n{messages[-2:]}"}],
    )
    new_facts = parse_json(response)
    for fact in new_facts:
        write_memory_file(fact)  # 写入 .memory/

前端类比

Selection 像搜索引擎的检索（先找相关文档再展示），Extraction 像埋点采集（用户操作后自动记录），Consolidation 像缓存 GC（超过阈值时清理合并）。

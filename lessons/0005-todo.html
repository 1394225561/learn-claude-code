第 5 课: TodoWrite — 任务规划

复杂任务需要规划。这一课给 Agent 一个任务板，让它先列计划再执行。

问题：Agent 闷头就干

你说"重构这个项目"，Agent 直接开始改代码。改到一半发现方向错了，又回头重来。

更好的方式：先列计划，再逐步执行，随时追踪进度。

任务板

CURRENT_TODOS: list[dict] = []  # 全局任务列表

def run_todo_write(todos: list) -> str:
    """更新任务板"""
    global CURRENT_TODOS
    CURRENT_TODOS = todos

    # 打印进度
    for todo in todos:
        icon = {"pending": "⬜", "in_progress": "🔵", "completed": "✅"}
        print(f"  {icon.get(todo['status'], '❓')} {todo['content']}")

    return f"Updated {len(todos)} todos"

定时提醒

如果 Agent 3 轮没有更新任务板，自动注入提醒：

rounds_since_todo = 0

# 在 agent_loop 中
if response.stop_reason == "tool_use":
    rounds_since_todo += 1
    if rounds_since_todo >= 3:
        # 注入提醒
        messages.append({"role": "user", "content": "⚠️ 请更新你的任务进度。"})
        rounds_since_todo = 0
关键洞察：TodoWrite 是规划能力，不是执行能力。它帮 Agent 组织思路，不做任何实际工作。就像一个白板——你在上面写计划，白板不会帮你干活，但能让你不迷路。

第 3 课: Permission — 权限系统

模型有了工具，但它想删文件就删文件。这一课加上三道安全门。

三道门

  工具调用请求
    │
    ▼
  ┌──────────┐
  │ Gate 1:  │ ── 命中黑名单? ──> 直接拒绝
  │ 硬拒绝    │
  └────┬─────┘
       │ 通过
       ▼
  ┌──────────┐
  │ Gate 2:  │ ── 匹配规则? ──> 需要用户确认
  │ 规则匹配  │
  └────┬─────┘
       │ 不匹配
       ▼
  ┌──────────┐
  │ Gate 3:  │ ── 用户输入 y/N
  │ 用户确认  │
  └────┬─────┘
       │ 确认
       ▼
    执行工具

代码实现

# Gate 1: 黑名单 — 绝对不能执行
DENY_LIST = ["rm -rf /", "sudo rm", "dd if=", "> /dev/"]

# Gate 2: 规则 — 需要用户确认
RULES = [
    {"name": "write_outside", "desc": "写入工作目录之外",
     "check": lambda args: not is_safe_path(args.get("path", ""))},
    {"name": "dangerous_bash", "desc": "危险的 bash 命令",
     "check": lambda args: any(kw in args.get("command", "")
                                for kw in ["rm ", "sudo", "shutdown"])},
]

def check_permission(block) -> bool:
    # Gate 1: 硬拒绝
    for keyword in DENY_LIST:
        if keyword in str(block.input):
            return False

    # Gate 2: 规则匹配
    for rule in RULES:
        if rule["check"](block.input):
            # Gate 3: 用户确认
            answer = input(f"⚠️ {rule['desc']}。允许? [y/N] ")
            if answer.lower() != "y":
                return False

    return True
前端类比：Gate 1 像 CSP（内容安全策略），Gate 2 像路由守卫，Gate 3 像 window.confirm()。

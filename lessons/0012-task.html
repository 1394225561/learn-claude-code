第 12 课: Task System — 任务系统

TodoWrite 只是计划列表。这一课建立一个持久化的任务图，支持依赖关系、所有权、跨会话恢复。

Task 数据结构

@dataclass
class Task:
    id: str                          # "task_1718000000_1234"
    subject: str                     # 任务标题
    description: str                 # 详细描述
    status: str                      # pending | in_progress | completed
    owner: str | None                # 谁在做（Agent 名字）
    blockedBy: list[str] | None      # 依赖的前置任务 ID

每个任务保存为 .tasks/{id}.json——文件即数据库。

依赖关系

  task_build ──────> task_test ──────> task_deploy
  (构建)            (测试)            (部署)
                    blockedBy:        blockedBy:
                    [task_build]      [task_test]

def can_start(task_id: str) -> bool:
    """检查所有依赖是否已完成"""
    task = load_task(task_id)
    for dep_id in task.get("blockedBy", []):
        dep = load_task(dep_id)
        if not dep or dep["status"] != "completed":
            return False  # 还有未完成的依赖
    return True

状态流转

def claim_task(task_id, owner):
    """领取任务：pending → in_progress"""
    task = load_task(task_id)
    if not can_start(task_id):
        return "Blocked by dependencies"
    task["status"] = "in_progress"
    task["owner"] = owner
    save_task(task)

def complete_task(task_id):
    """完成任务：in_progress → completed"""
    task = load_task(task_id)
    task["status"] = "completed"
    save_task(task)
    # 扫描下游，报告新解锁的任务
    for other in load_all_tasks():
        if task_id in (other.get("blockedBy") or []):
            if can_start(other["id"]):
                print(f"🔓 {other['subject']} is now unblocked!")

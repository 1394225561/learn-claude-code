第 19 课: MCP — 模型上下文协议

Agent 只能用内置工具？这一课通过 MCP（Model Context Protocol）让外部工具插件化接入。

什么是 MCP？

MCP 是 Anthropic 定义的一个标准协议，让 AI Agent 能够发现和调用外部服务器提供的工具。就像 USB——你不需要知道鼠标、键盘、U 盘的内部实现，只要它们遵守 USB 协议就能即插即用。

核心思路

# 工具命名规范：mcp__{服务器名}__{工具名}
mcp__github__create_pr
mcp__slack__send_message
mcp__database__query

def assemble_tool_pool():
    tools = list(BUILTIN_TOOLS)
    handlers = dict(BUILTIN_HANDLERS)

    for server_name, client in mcp_clients.items():
        for tool_def in client.tools:
            # 规范化命名
            prefixed = f"mcp__{normalize(server_name)}__{normalize(tool_def['name'])}"
            tools.append({"name": prefixed, ...})
            # 用 lambda 捕获当前值（避免闭包陷阱）
            handlers[prefixed] = lambda *, c=client, t=tool_def["name"], **kw: c.call_tool(t, kw)

    return tools, handlers
闭包陷阱：在 for 循环中创建 lambda 时，如果不使用默认参数捕获（c=client），所有 lambda 会共享同一个变量，最终都指向最后一个 client。

前端类比

这就是 VS Code 的扩展系统或浏览器扩展架构。宿主（Agent）定义插件 API，外部服务（MCP 服务器）注册能力，宿主动态添加到命令面板。mcp__server__tool 命名就像 VS Code 扩展命令 ID（extension.commandName）。
